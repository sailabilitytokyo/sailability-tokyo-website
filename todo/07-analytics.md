# 07. Google Analytics の設定

サイト側の計測の仕組みは入れてあります（測定 ID `G-M389XQJK35`、`src/data/site.yaml` の `analytics`）。
**本番ドメイン（www.sailabilitytokyo.jp）でだけ計測する設定**なので、仮公開 URL（workers.dev）やローカルでは計測されません。ドメインを切り替えるまでは、今の Google Sites が同じ測定 ID で計測を続けます（データは途切れません）。

Google Analytics の画面（https://analytics.google.com/ ）で、次を設定してください。画面の名前は変わることがあるので、見つからなければ AI にスクリーンショットを見せて相談してください。

## いま設定しておくこと

- [ ] **測定 ID の確認**: 管理（左下の歯車）→ データの収集と修正 → データストリーム → ウェブのストリームを開き、測定 ID が `G-M389XQJK35`、URL が `https://www.sailabilitytokyo.jp` になっているか確認
- [ ] **拡張計測機能を ON**: 同じストリームの画面で「拡張計測機能」を ON（ページの表示・スクロール・外部サイトへのリンクのクリックが自動で計測される）
- [ ] **データの保持期間を14か月に**: 管理 → データの収集と修正 → データ保持 →「イベントデータの保持」を **14か月** に（初期値は2か月。小学生ヨット教室の募集時期を前の年と比べるため）
- [ ] **Google シグナルは OFF のまま**: 管理 → データの収集と修正 → データ収集（広告のためにユーザーを追跡する機能。このサイトには不要。プライバシーの面でも OFF がおすすめ）
- [ ] **キーイベントを登録**: 管理 → データの表示 → イベント（または キーイベント）→「新しいキーイベント」で次の2つを作成
  - `reserve_experience`（セーリング体験会の「予約する」ボタン）
  - `apply_junior_course`（小学生ヨット教室の「申し込む」ボタン。募集期間中だけ表示）

## 本番公開の後に確認すること（todo/05 と一緒に）

- [ ] レポート → **リアルタイム** を開いた状態で、スマホなどから https://www.sailabilitytokyo.jp/ を開き、自分のアクセスが表示されるか
- [ ] セーリング体験会の「予約する」ボタンを押して、リアルタイムに `reserve_experience` が出るか
- [ ] （任意）自分や関係者のアクセスを除外: 管理 → データストリーム → タグ設定を行う → 内部トラフィックの定義 で、自宅などの IP アドレスを登録

## 数字の見方

| 知りたいこと | 見る場所 |
| --- | --- |
| 何人が見たか | レポート → エンゲージメント → ページとスクリーン |
| 予約・申し込みボタンが何回押されたか | レポート → エンゲージメント → イベント（`reserve_experience` / `apply_junior_course`） |
| どこから来たか（検索・Instagram など） | レポート → 集客 → トラフィック獲得 |

- Google フォームは別サイトなので、**実際に送信されたかは GA では分かりません**。送信数はフォームの回答数で確認します。
- Instagram やチラシからどれだけ来たかを知りたいときは、リンクの末尾に `?utm_source=instagram` のような目印を付けると、集客のレポートで区別できます（AI に「Instagram 用の計測付きリンクを作って」と頼めば作れます）。

## プライバシーポリシーへの記載

- [ ] Google Analytics の利用規約では、**Google Analytics を使っていることと、Cookie を使うこと**をサイトに明記する必要があります。今のプライバシーポリシーには書かれていないので、AI が文案を作って追加します（内容を確認して OK を出してください）

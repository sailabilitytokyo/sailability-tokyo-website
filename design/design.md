## 1. デザインコンセプト

- **コアテーマ**: 無限のエネルギー、楽観主義、冒険心
- **キーワード**: 気分を高揚させる (Uplifting)、刺激的 (Stimulating)、目を引く (Attention-Grabbing)
- **このサイトの目的**: **「ハンザに乗りたい」と思ってもらうこと。** そして、乗るまでの足止め要素（泳げない・歳だから・子どもが小さい・予約が面倒）を先に解消すること。

### 想定読者

1. 豊洲・江東区周辺に住む30〜40代、小学生の子を持つ親御さん
2. 60代以降、仕事をリタイア／子育てが終わり、海にあこがれのある方
3. 豊洲市場・千客万来・チームラボ・豊洲公園に来た観光のお客さま

乗船場: 豊洲ぐるり公園乗船場 ／ セーリング水域: 東電堀

## 2. カラーシステム

「Summer Sky」の5色。

| 役割 | カラー名 | HEX | トークン |
| :--- | :--- | :--- | :--- |
| Primary Text / Heading | Persian Blue | `#072AC8` | `--sst-persian-blue` ／ `--text-heading` |
| Primary CTA | School Bus Yellow | `#FFC600` | `--action-primary-bg` |
| Secondary Action | Dodger Blue | `#1E96FC` | `--text-link` ／ `--action-secondary-bg` |
| Accent / Highlight | Bright Lemon | `#FCF300` | `--accent-highlight` |
| Background / Base | Icy Blue | `#A2D6F9` | `--surface-base` |

### ロゴのネイビー

`#3C527B`（`--sst-logo-navy`）はロゴマークの実測インクです。**ロゴ専用**で、UIの色としては使いません。

### 派生ランプ

- Blue: `--sst-blue-50 / 100 / 200 / 400 / 500 / 600 / 700 / 900`
- Sky: `--sst-sky-50 / 100 / 200 / 300 / 400 / 500 / 600`
- Yellow: `--sst-yellow-200 … 700`、`--sst-lemon-200 / 400`
- Neutral: `--sst-neutral-25 … 900` ／ **純グレーは使わず、すべて青みを帯びた中性色**

### ステータス

| 用途 | 文字色 | 背景 |
| :--- | :--- | :--- |
| 受付中 | `#0E8A5F` | `#E4F6EE` |
| 残りわずか | `#B88900` | `#FFF6DB` |
| 満席・中止 | `#C81E3C` | `#FDEBEE` |
| お知らせ | `#0A6CC2` | `#E1F1FE` |

### 運用ルール

- **1ページに背景色は2つまで**（白＋Icy Blue、または白＋Persian Blue-700）。
- セマンティックトークン（`--text-body`, `--surface-card`, `--border-subtle` など）を先に使い、生の `--sst-*` は必要なときだけ。
- 文字を不透明度で薄くしない。淡い文字は**薄い色のトークン**を使う。

## 3. タイポグラフィ

| 用途 | フォント | トークン |
| :--- | :--- | :--- |
| 欧文・UI | **Figtree** | `--font-sans` |
| 和文 | **Noto Sans JP** | `--font-jp` |
| ロゴタイプ | セリフ体イタリック（ロゴ画像内に描かれている） | **本文には使わない** |

### サイズ

**本文は17px（`--text-base`）、行間1.85（`--leading-relaxed`）。** 読者は小学生から70代までいます。本文をこれより小さくしないでください。

| トークン | px | 用途 |
| :--- | :--- | :--- |
| `--text-md` | 19 | リード文 |
| `--text-base` | 17 | **本文標準** |
| `--text-sm` | 15 | 補足・カード本文 |
| `--text-xs` | 14 | キャプション |
| `--text-2xs` | 13 | 注釈 |
| `--text-3xs` | 12 | バッジ |

見出しは可変サイズ: `--display-hero` (36→64px) / `--display-section` (28→40px) / `--display-card` (20→26px)。

### ウェイトと組み

- 400 本文 ／ 500 ラベル ／ 700 見出し ／ **900 は数字のみ**（1,500円、全6回、20分）
- 見出しのトラッキング `-0.02em`、行間 1.18
- 和文は `font-feature-settings: "palt"` と `text-wrap: pretty` を常時適用
- 1行の長さは42emまで（`--measure-body`）
- 英字のアイブロウ（PROGRAM / NEWS）は大文字＋`--tracking-caps`（0.12em）

## 4. 余白・かたち

- 4pxスケール（`--space-1` 〜 `--space-32`）
- セクション間は `--section-y` = `clamp(56px, 7vw, 112px)`
- 左右の余白は `--gutter` = `clamp(20px, 5vw, 48px)`、コンテンツ幅は最大1160px

### 角丸

| トークン | 値 | 用途 |
| :--- | :--- | :--- |
| `--radius-md` | **8px** | ボタン・入力欄 |
| `--radius-lg` | **12px** | カード |
| `--radius-xl` | 20px | ダイアログ |
| `--radius-pill` | 999px | タグ・スイッチ |

### タップ領域

**最小48px**（`--tap-min`）。子どもと高齢の方が操作します。小さいボタンでも40pxを下回りません。

### カード

白／1pxの細い罫（`--border-subtle`）／角丸12px／**通常時は影なし**。
クリックできるカードだけ hover で影と浮き上がりが出ます。
最重要のカードにだけ、上辺に4pxの黄色ライン（`accent`）。
**角丸カードに左だけ色帯、は使いません。**

### 影

すべて Persian Blue で色づけします（`rgba(7,42,200,…)`）。グレーの影はこの配色では汚れて見えます。
フォーカスは Dodger Blue の3pxグロー＋2pxアウトライン。

## 5. 状態とモーション

| 状態 | 挙動 |
| :--- | :--- |
| hover（主ボタン） | School Bus Yellow → Bright Lemon に明るく＋2px浮く |
| hover（副ボタン） | 1段濃く＋2px浮く |
| hover（カード） | 4px浮く＋`--shadow-lg` |
| press | `scale(0.98)` ＋1段濃い色。**色変化だけで済ませない** |
| focus | 2px アウトライン＋2px オフセット。**絶対に消さない** |
| disabled | `opacity: .42`、影なし、変形なし |

| トークン | 値 | 用途 |
| :--- | :--- | :--- |
| `--duration-fast` | 140ms | hover / press |
| `--duration-base` | 220ms | 面の変化 |
| `--duration-slow` | 380ms | ダイアログ |
| `--ease-swell` | `cubic-bezier(.37,0,.24,1)` | 立ち上がって静まる。ヨットが傾いて戻る感じ |

**バウンド・回転・パララックス・スクロールジャックは使いません。** `prefers-reduced-motion` は全体で尊重します。

透明・ぼかしを使うのは、固定ヘッダー（`rgba(255,255,255,.92)` ＋ 10px blur）とダイアログのスクリムだけ。

### 固定要素

固定ヘッダー（76px）と、黄色の固定ボトムバー（次の開催日と予約ボタン）。

## 7. 写真

**明るく、彩度を落とさず、人が写っているカットを優先。**
青い水面、白い艇体、ピンク・ライム・ターコイズのセール、背景に豊洲のスカイライン。
モノクロ・グレイン・強いカラーグレーディングは使いません。
**艇だけの写真より、人が乗って笑っている写真のほうが仕事をします。**

| 用途 | トークン |
| :--- | :--- |
| ヒーロー（白文字を左に置く） | `--scrim-full` |
| カード内の見出し重ね | `--scrim-bottom` |

不足している素材: 車いすの乗り移り、法人ロゴの入ったセール、法人会員のロゴ。

## 8. アイコン

**Lucide**（アウトライン、2pxストローク、丸いキャップ）。`src/icons/` に SVG を置き、`<Icon name="..." />` で使います。
サイズ: 14（タグ内）／16–18（ボタン・行）／20（標準）／24–26（特集ブロック）

**絵文字は使いません。** 見出し・ボタン・お知らせのいずれにも使いません。

## 9. 文章のトーン

- 日本語・ですます調。英語は小さなアイブロウ（PROGRAM、NEWS）とロゴタイプのみ。
- 「当団体」「弊社」は使わない。読者と水面の間に机を置かない。
- **一文にひとつの事実。** 感情より先に事実。
- 数字は大事な情報。料金・時間・回数・対象学年は埋もれさせない。
- 見出しは招く調子で平易に。感嘆符・「〜しませんか？」の連発は避ける。

良い例:

> 予約なしでも、その場で乗れます。1回20分。インストラクターが隣に同乗します。

避ける例:

> 圧倒的な海洋体験をあなたに！！
> 当団体では体験乗船会を随時実施しております

使う: ハンザ / セーリング / 乗船 / 体験会 / 開催日 / インストラクター / 乗船場 / 東電堀
避ける: 弊団体 / 実施しております / 随時 / 〜となります / ※注意書きの多用

## 10. アクセシビリティ

1. **黄色系を文字色に使わない。** 黄色は「面」と「装飾ライン」に限定。NEW バッジも黄色は背景、文字は Persian Blue。
2. **コントラスト比。** 本文は `--text-body`（#242B3D）または `--text-heading`（Persian Blue）。どちらも白地で4.5:1以上。
3. **フォーカスリングを消さない。**
4. **タップ領域48px以上。**
5. ツールチップに、行動に必要な情報（料金・安全・時間）を入れない。
6. `prefers-reduced-motion` を尊重。

## 11. ボタンの原則

- **1画面に primary（黄色）はひとつだけ。** そのページが何をしてほしいのかを一意にします。
- `inverse`（白）は濃い青の帯や写真ヒーロー用。
